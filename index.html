OpenClaw Email Briefing

A personal email assistant that prepares a morning summary of important messages from accounts its owner explicitly connects.

How it works

The app uses the Gmail API with read-only access to search messages and read relevant threads. The owner's OpenClaw server processes the selected messages with an OpenAI model and posts a concise summary in the owner's private Discord channel.

It does not send, delete, archive, or mark messages as read. Each mailbox requires separate Google authorization. Connecting an account to Spark does not authorize this app.

Personal use

This is a private integration operated by its owner, not a public email service. This public website contains information only. It does not sign users in or collect mailbox data.
