OpenClaw Email Briefing

Privacy policy

Effective 23 October 2026. This policy describes the personal OpenClaw Email Briefing integration.

Information accessed

For each separately authorized Gmail account, the app uses read-only Gmail API access to search messages and read message metadata and relevant email threads. This can include addresses, subjects, dates, labels, and message text. OAuth credentials allow the server to continue the authorized access without the owner's PC. The briefing workflow does not download attachments.

Purpose and processing

The information is used to identify important emails and prepare the owner's morning briefing. Processing takes place on the owner's Hetzner OpenClaw server. Selected email content may be sent to OpenAI to generate the summary. The resulting summary is delivered to a private Discord channel selected by the owner. These services process the data according to their applicable terms and privacy policies.

The app does not sell Google user data, use it for advertising, or use it to train machine learning models. OpenClaw Email Briefing's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and protection

OAuth tokens are stored in an encrypted file keyring on the owner's server, with restricted filesystem permissions. Server execution records and model conversation history may retain selected message content or summaries. Discord retains posted briefings until they are deleted. The owner controls the server and the destination channel; access depends on their configuration.

Retention and control

Retained server records and Discord summaries remain until the owner deletes them under the relevant service's retention settings. The owner can disable the scheduled job, remove stored account credentials, and delete server records or Discord briefings. Google access can be revoked at any time in Google Account connections. Revocation stops future authorized API access but does not automatically delete existing server records or Discord messages.

This website and contact

This GitHub Pages site is informational and contains no mailbox content or OAuth credentials. GitHub may process ordinary website request information under its own privacy statement. For questions or deletion requests, use the support email displayed on this app's Google consent screen.
